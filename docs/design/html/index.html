Starfish UI mockups

Static HTML pages exported from the Starfish design canvas. Open any page in a browser; the links between screens work.

Design mockups, partly built. The app today has Overview, Incidents, the incident evidence page, Runs and an editable Settings page (On-call for admins), with sign-in, access denied and 404; each built page differs from its mockup, and the Live runs per-step cards, the deploy and recovery steps and the Healed channel are not built. These pages are designs, not captures of the product, and every value on every page is illustrative. Decisions behind the designs: docs/design/mockups.md.
